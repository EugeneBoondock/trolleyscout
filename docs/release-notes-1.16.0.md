# Trolley Scout 1.16.0+46 release notes

## Consumer app

### Google Play release notes

- Discover campaigns in Marketplace, Window Shopping, and Stories.
- See more useful shopping content from participating businesses.
- Get improved retailer and catalogue discovery across supported regions.
- Receive clearer update prompts when a newer app version is available.
- Includes performance, reliability, and data-quality improvements.

### Internal release summary

- Adds support for the Developers subscription and developer access profile.
- Adds scoped API-key access for public developer API requests.
- Adds OAuth 2.1 with PKCE for the Trolley Scout MCP server.
- Adds read-only developer access to deals, catalogues, stores, stories, and trends.
- Adds campaign placement across Marketplace, Window Shopping, and Stories.
- Expands retailer scouting, source health reporting, and location normalization.

## Business app

### Google Play release notes

- Create campaigns for Marketplace, Window Shopping, and Stories.
- Save drafts, submit campaigns, pause campaigns, and review campaign results.
- View daily, weekly, or monthly performance for views, saves, and link clicks.
- See which campaigns and placements are attracting the most attention.
- Receive in-app update alerts with a direct route to the latest business app.
- Includes refreshed business-facing screenshots and interface improvements.

### Internal release summary

- Adds Today, This week, and This month insight periods.
- Reports impressions, enlarged image views, saves, link clicks, destination results, and top campaigns.
- Gives platform admins an Act as business mode for viewing the business interface.
- Lets admins choose an approved business, inspect the same content and navigation, then return to admin mode.
- Adds owned campaign operations for subscribed developers: create drafts, submit, pause, and read results.
- Separates business-facing screens from platform administration screens.
